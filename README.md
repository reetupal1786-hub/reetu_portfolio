## 🛠️ Technical Tools & How I Use Them

Here is a breakdown of the core tools integrated into my projects and data workflows:

### 1. 🐍 Python (Data Wrangling & EDA)
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
* **Core Application:** Used for data ingestion, cleaning missing values, handling duplicates, and filtering outliers. I leverage **Pandas** for structuring tabular data, **NumPy** for vector computation, and **Matplotlib/Seaborn** to create statistical plots to spot hidden market patterns.

### 2. 🛢️ SQL & MySQL (Database Querying)
* **Core Application:** Used to query, filter, and extract subsets from large transactional databases. 
* **Key Skills:** Writing optimized queries using Joins, Subqueries, Aggregate Functions (GROUP BY, HAVING), and Window Functions to prepare clean data models for visualization.

### 3. 📊 Power BI (Business Intelligence & Dashboards)
* **Core Application:** Used to build end-to-end interactive reporting systems.
* **Key Skills:** Data preparation inside **Power Query ETL**, implementing analytical relationships via **Star Schema Data Modeling**, and writing customized **DAX measures** (Data Analysis Expressions) to track complex corporate KPIs.

### 4. 📈 Microsoft Excel (Spreadsheet Analysis)
* **Core Application:** Used for rapid prototyping, deep-dive data auditing, and structural calculations.
* **Key Skills:** Advanced dynamic charting, Pivot Tables, Conditional Formatting, VLOOKUP/XLOOKUP, and complex nested conditional formulas.
